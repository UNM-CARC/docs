# Getting started

New to CARC? Start here: accounts, policies, logging in, and moving data.

* [Getting started at CARC](overview.md) - Create a CARC account, join a project in ColdFront, and find support.
* [Good Neighbor Use Policy](good-neighbor-policy.md) - Acceptable-use rules that all CARC users agree to: account sharing, data restrictions, job monitoring, and security.
* [Logging in to CARC systems](logging-in.md) - Connect to CARC clusters with SSH from Linux, macOS, or Windows.
* [Password reset and one-time passwords](password-reset.md) - Reset your CARC password and manage one-time-password (OTP) settings.
* [SSH keys and client configuration](ssh-keys.md) - Generate SSH key pairs and configure your SSH client for convenient, secure logins.
* [X11 forwarding](x11-forwarding.md) - Display graphical applications from CARC machines on your local screen with X11 forwarding.
* [Transferring data](transferring-data.md) - Move data to and from CARC systems with scp, rsync, sftp, and Globus.
* [Learning Linux resources](learning-linux.md) - Curated external resources for learning the Linux command line.
