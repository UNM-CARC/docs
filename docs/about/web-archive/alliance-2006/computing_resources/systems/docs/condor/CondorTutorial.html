The Condor User Tutorial Workbook

In order to give you a hands on tutorial of Condor, we have built a set of excercies to go through.

Each example has its own web page. Please read the instructions carefully. Any lines that begin with "% " are commands that you should execute in your command window (the xterm on the left-hand side of your screen).

Please click on the appropriate link below to find instructions for the desired excercise. -

  1. Submitting and Monitoring a Simple Test Job
  2. Submitting Jobs With Requirements and Rank
  3. Submitting a Large Clusters
  4. Using DAGMan

For More Information

More information about Condor including the Condor Manual is available off of the Condor web site: http://www.cs.wisc.edu/condor. If you have any problems with Condor, you can ask us about it by sending mail to condor-admin@cs.wisc.edu
