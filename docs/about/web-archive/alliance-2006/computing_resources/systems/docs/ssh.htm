SSH DOCUMENTATION

SSH Keys

ssh_known_hosts are the ssh keys for protocol 1.
Copy these files to ~/.ssh/known_hosts

ssh_known_hosts2 are the ssh keys for protocol 2.
Copy these files to ~/.ssh/known_hosts2

Both files contain entries for both sides of the network.

SSH:

Users must use secure-shell when connecting to other HPC@UNM systems once logged in.

% ssh nambe.hpc.unm.edu

% ssh blackbear.hpc.unm.edu

% ssh loslobos.alliance.unm.edu

% ssh roadrunner.alliance.unm.edu
