Accounts

User Accounts at the Center for HPC@UNM are authorized primarily for UNM faculty, staff, and students associated with an HPC approved research project. If you are not currently associated with an HPC approved project and want to apply for a project account, please refer to the Project Application Overview for requirements.

An Acceptable Use Agreement must be signed and submitted at the same time the User Account Application form is submitted. To expedite applying for a User Account be sure you know the ID number for the project that you will be working on. If you don’t know the project ID number, please contact the project PI to obtain the ID number.

Once your user account application is approved you will be issued your login information. You should receive a “New User Packet” containing your temporary password and login information via US Postal Services approximately 8 - 10 working days after you submitted your User Account Application.
