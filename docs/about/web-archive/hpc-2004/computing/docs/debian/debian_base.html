How to build a Linux System at the AHPCC

Base Diskettes

In order to install Debian Linux, you must either have a Debian install CD or following diskettes. If you are able to boot directly from the CD you do not need any of the diskettes. If, on the other hand your computer will not boot directly from the CD, but you do have the install CD, you will need the Rescue Floppy only.

It is assumed that you are using a 1.44 Mb diskette drive. If not, download the appropriate diskettes from the net. These images are updated periodically, and it is probably a good idea to download the diskettes from the net anyway.

resc1440.bin "Rescue Floppy"
drv1440.bin "Device Drivers"
base-1.bin "Base 1"
base-2.bin "Base 2"
base-3.bin "Base 3"
base-4.bin "Base 4"
base-5.bin "Base 5"
