This is a short "how to get started with CDE" information document.

Warning: These pages are not up to date and are currently being reconstructed.

The Common Desktop Interface is a tool which allows the user to create a work environment suited for their needs.

The easiest way to launch any of the programs in CDE is to hold down the right most mouse button and choose "programs" from the scroll down window that appears on the screen. Once "programs" is chosen, a pop down list of all the available programs will appear and the user can select any one of them.

TO END YOUR CDE SESSION AND LOGOUT, CHOOSE LOGOUT FROM THE SCROLL DOWN WINDOW THAT APPEARS BY CLICKING THE RIGHTMOST MOUSE BUTTON.

The control panel is divided into the right panel and the left panel and is described briefly in rest of this document.

The Right Panel

You can click on the second (from right) item which has a deck of books with a question mark on them, and you will enter a help environment. This document is being developed based on the information available in the help environment.

A good introduction to the common desktop environment can be obtained by taking a "Tour of the Main panel" and a "Tour of the Subpanels" in the help environment (Help Viewer).

To learn how to perform a specific task within the CDE, click on "Index" in the Help Viewer and find the word which suits your needs.

If you click on the third item from the right(a folder with calculator and pencil etc) you will open the application manager. Within application manager, a lot of useful applications can be found in the "Desktop_Apps". By clicking on "Desktop_Apps" you can get access to many useful applications such as "calendar", "terminal", "text editor" etc. It is not too difficult to use these applications, one has to get used to them. You can launch any of these applications by clicking on the application icon. ( Note that clicking on "terminal" gives you a terminal window but this is not an Xterm window. To get an xterm window, you have to go into "Desktop tools" and click on "xterm".)

The forth item from the right is style manager and will allow you to change your screen backdrop etc in a very simple fashion. A cute feature of this application is the "color" chooser. "Color" will allow you to pick the color of your desire as the background color of your screen, furthermore it will tell you the "number of your color" which is interesting to people like me who really like to customize the environment. Using the"number of color" you can make a color which is not listed in the pull down window.

If you click on Desktop tools, you will get another set of useful applications such as the "vi text editor" and "xterm".

The fifth icon from the right is the print manager. To use it just click on it and follow your gut and Tom Sahs's advice.

The left panel

The first icon from the left is a clock.

The second icon is for the calendar. If you click on this it will launch the calendar application. "Calendar" has some cute features such as "reminders of appointments" by popping up windows on your screen and making the terminal beep. You can also print your schedule of appointments in several different formats. One has to play with the application or read the help pages on it in order to learn how to use it.

The third icon is the file manager. It lets you make directories etc. It also lets you move files around and delete them easily.

The forth icon is one that you can install in the control panel. If you click on the arrow above the forth icon, a pop up list of your personal applications will appear. The first item in this list is an "install icon". If you wish to install an icon for any of the applications, grab the icon for that application and drag it into the "icon installer". From now on you can just hit the arrow on top of the forth icon and click on your application.

If you wish to remove an icon from the pop up list described above, click with the rightmost mouse button, on the icon to be removed and choose delete. If you click on an icon with your rightmost mouse button and choose "add to control panel", that icon will become the forth icon from the right in the control panel.

Enough said!!!! Now you have to play with it.
