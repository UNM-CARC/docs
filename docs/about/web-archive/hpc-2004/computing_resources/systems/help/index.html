USER SERVICES

The User Services Group at HPC@UNM is committed to providing high qualify services that assists the center’s users effectively utilize the HPC resources and services available to them.

HPC@UNM primarily provides resources to UNM faculty, post-docs and PIs with funded research projects who have a need for high-performance computing resources. HPC also provides resources to a limited number of projects with partners, collaborators, state and federal agencies, and local businesses in order to foster greater economic competitiveness. All projects must be evaluated and approved prior to applying for a user account.

Services available include:

Accounts
Help Desk
Consulting
Documentation
Training
Outreach
