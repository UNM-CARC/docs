HIGH PERFORMANCE COMPUTING

Researchers always want higher processing speed and more memory in order to investigate increasingly complex problems or obtain results more quickly. Examples of several classes of problems that require faster processing are:

Simulation and Modeling problems based on successive approximations or more calculations and more precise.

Problems dependent on computations/manipulations of large amounts of data such as climate modeling or fluid turbulence
