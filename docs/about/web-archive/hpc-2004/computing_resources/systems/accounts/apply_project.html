Project Application Overview

What is a Project?

In general, we assign a Project to each new line of investigation using Center resources. For the Principal Investigator, a Project provides a way to track resource usage. Projects are also tied to funding sources and to resource allocations.

Operationally, projects are managed by a Principal Investigator and coalesce the Accounts and usage of many different people working on the Project.

Project applications are generally reviewed for (i) applicability to the desired resources, (ii) the scientific or research to be conducted, and (iii) qualifications of the PI. As a rule of thumb, PI's will normally be faculty or research faculty at UNM or other schools.

Project Applications

A Project application can be submitted by the Project PI or a researcher associated with the project. If you are not the Project PI you will be asked to provide the following information:

  • PI’s Name
  • PI’s E-mail Address
  • PI’s Phone Number
  • PI’s Office Mailing Address
  • PI’s Institutional Affiliation
  • Project Description

The application must have all of the required fields filled in. If the project form is completed by someone other than the project PI the PI will be notified that a new project application has been submitted and must submit his/her OK before the project can be approved. As soon as the Center for HPC approves the project you will be notified by email. It is at this time you should apply for a user account if you don’t already have one.
