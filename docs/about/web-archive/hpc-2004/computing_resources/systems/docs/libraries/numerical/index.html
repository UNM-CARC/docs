Performs serial dense linear algebra operations with a high level of efficiency.  Solves linear equations, linear least squares  problems, standard and general eigensystem problems, and singular value problems.  Routines are callable from Fortran program.   The name LAPACK is acronym for Linear Algebra PACKage

BLAS

Serial library of basic linear algebra computations and supports 3 levels of operations.  Level 1 is between 2 vectors (e.g, addition or dot product of 2 vectors).  Level 2 is between matrix and vector (e.g., matrix-vector multiplication), and level 3 is between 2 matrices (e.g., matrix-matrix multiplication).  The name BLAS is acronym for Basic Linear Algebra Subprograms.
