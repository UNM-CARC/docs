VMware online support page for HPC@UNM

 

Introduction:

This online support page is intended for user reference and is supplemental to the help desk services. Basically with this page you should be able to run VMware successful and find some answers to questions you may have about VMware.

Hardware Capability:

VMware is intended for use on the Truchas cluster located in the workshop room at HPC@UNM. The Truchas Cluster is a cluster of Dual Processor Pentium III 650 MHz running Red Hat Linux 7.2.3 Kernel Version 2.4.18. Users can take advantage of this tremendous computing power by running two operating systems simultaneously through the software known as VMware.

Why not just use lilo and dual-boot the computers?

The workshop computers are also known as the Truchas Cluster here at HPC@UNM and because of their intense computing power they are used as a cluster and run a type of software called Condor. This software would be interrupted on reboot of any single one of the Truchas computers. VMware allows for guest operating systems to be started without reboot of the computers and even shares processor power with Condor if needed. Not only that but VMware allows for multiple operating systems to be stored on all Truchas computers. So on the administrative level this makes tasks like imaging and software installation efficient. The Truchas cluster is also used as a place for workshops at HPC@UNM so with VMware running any user can still login to the machine remotely while a workshop is going on.

Getting Started:

Follow these easy steps and you will be on your way running VMware.

  1. Run a script placing a necessary file in your account.
    At a command prompt type:

    ~vmware/scripts/vmware-licenselinker.sh

  2. Start VMware.
    At a command prompt type:

    vmware &

  3. Choose which operating system you wish to run.
    Double click the corresponding configuration on the startup screen.

  4. No Configurations?
    If there are no configurations to choose from click on the File menu ~> Open. A window will pop up and there you can navigate to the file directories until you get to /vmware. Here are located all the operating systems and their configurations. Find the operating system that you need and click on its corresponding configuration. For example if you need the NT5 image for the bio544 class go to /vmware/bio544/win2000/ and click on the win2000.cfg file. or type the whole path into the Selection prompt located right above the [OK] [Filter] [Cancel] buttons. Then click [OK]. (This should only happen on the rare instances of the fresh installation of a guest operating system).

  5. Power on.
    Click the [Power On] button in the upper left hand of the VMware window.

  6. Change in and out of Full Screen mode.
    Click the [Full Screen] button to bring VMware to the full screen.
    To bring VMware out of this mode press [CTRL] + [ALT] + [ESC] simultaneously.

    Reminder: If you are running your guest operating system in window mode the mouse will jump between operating systems as you move the mouse pointer arrow in and out of the VMware window to reclaim your mouse arrow to the Linux side press [CTRL] + [ALT] + [ESC]. To give it back to the guest operating system simply click inside the VMware window.

  7. Your guest operating system should now be booting up just wait for a normal user login prompt and sign in as usual.

Finishing Up:

To close up vmware follow these steps.

  1. Make sure you have saved any work or data on a network drive or floppy disk.

  2. Shutdown the guest operating system as usual.

  3. If you are in Full Screen mode press [CTRL] + [ALT] + [ESC] simultaneously to place VMware in window mode.

  4. When the guest operating systems says it is safe to power off. Click the [Power Off] button again in the upper left hand corner of the VMware window.

  5. Close VMware

Operating Systems:

Currently Available on the Truchas cluster is a Microsoft Windows NT4 configuration and a Microsoft Windows 2000 configuration. Accessibility to these configurations change depending on class and workshops that may be going on in the lab at the time. Both configurations have adequate office suite software installed. Requests for additional software can be made (as usual) via the help desk.

Caveats:

A setting in VMware can be set where all data written to the guest operating system disk will be lost at shutdown so if you have any data please save it to a floppy disk or mounted network drive. VMware supports the mounting of network drives and the use of floppy disk storage. Zip drives, however, are currently unsupported by VMware.
