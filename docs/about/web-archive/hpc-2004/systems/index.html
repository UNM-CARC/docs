Center Supported Software Projects

 


LoGS

LoGS is a log analysis engine that attempts to address many of the issues with maintaining larger networks or cluster style machines. LoGS has a dynamic ruleset, is able to look for one or more messages before triggering an action, and has a powerful programming language used for configuration and extension. With proper ruleset construction, LoGS is a very efficient log analysis engine.


AIRS

AIRS is an integrated job accounting and user management tool, designed for managing computers that run batch schedulers.
