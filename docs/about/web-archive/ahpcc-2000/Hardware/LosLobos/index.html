Los Lobos

Datasheet

System Configuration

  • 512 Intel Pentium III 733 MHz processors
  • IBM Netfinity 4500R nodes

Node Configuration

  • 1 GB RAM
  • 9 GB SCSI local storage for OS and local scratch
  • Myrinet high performance interconnect
  • RedHat 6.1 (2.2.13 kernel)

Mass Storage

  • 1 TB high performance RAID SSA storage
  • 2 TB hierarchical storage with ADSM
