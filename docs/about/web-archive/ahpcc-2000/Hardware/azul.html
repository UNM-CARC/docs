Azul

General User Information

Azul is the hardware side of the Vista Azul project between AHPCC and IBM Research. Azul is a research machine. Use is restricted to collaborators on the Vista Azul project. A cluster of 32 processors (8 4-way NetFinity nodes) is joined together with a cluster of 32 processor Winterhawk machines with a Scalable Graphics Engine (SGE) to create a parallel computing, rendering and displaying environment. Access is allowed only to users who have been approved for the project. Please contact Dr. Bob Ballance for more information.
