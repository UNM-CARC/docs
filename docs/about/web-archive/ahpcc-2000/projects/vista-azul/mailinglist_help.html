Vista Azul Mailing Help

AHPCC mailing lists are administered by the majordomo list-serv program. With majordomo, all list management requests are sent to majordomo@ahpcc.unm.edu. The request itself should be in the text (body) of the message, not in the message subject.

For example, to subscribe to vista-azul-announce, send mail to majordomo@ahpcc.unm.edu with the text subscribe vista-azul-announce in the message body.

Here are some things you can request

subscribe list-name subscribe to the named list, using your current email address
subscribe list-name email-address subscribe to the list, using an alternate email address
unsubscribe list-name remove yourself from the list, using your current email address
lists returns a listing of mailing lists
info list-name returns a description of the list

 

To post a message to a list, simply mail to that list at AHPCC. For example, to post a message to vista-azul-users, send mail to vista-azul-users@ahpcc.unm.edu
