Visualization

Integrating visualization hardware and software into this configuration permits our joint research to address end-to-end issues in using computation to model and simulate large and difficult problems.
  • Integration of graphics and visualization in mixed hybrid environment
  • Interactive graphics and steering of complex computations
  • Graphics interoperability
  • Parallel rendering using either software, software and hardware, or hardware only solutions
  • High performance graphics using SGE
  • Remote visualization using SGE possibly involving compression methods for transmission over the Access Grid
