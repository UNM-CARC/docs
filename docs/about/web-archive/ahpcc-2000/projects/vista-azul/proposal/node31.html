Planned Software And Tools To Be Developed

The following software components have been identified as candidates for development at AHPCC in support of this effort:

  • Drivers Between The high performance COTS interconnects And the SP (in consultation with IBM) Switch. If there is no proprietary issue, prepare such a driver modeled after the Monterey/Linux driver, if this is possible and reasonable. If there is a proprietary issue, investigate a design for this and possibly other drivers that separates the drivers into a mostly non-proprietary part and a necessary proprietary part that is dependent only on the proprietary switch technology
  • Myrinet drivers for the Netfinity (in consultation with Myricom)
  • 3D Linux drivers for the GTX2000P graphics cards.
