Visualization Research

The planned work will port, develop, and study a general virtual environment designed to facilitate the understanding of complex high performance software codes, coexecuting on a cluster-based machine. Our on-going project involves interfacing virtual reality (VR) environments to high performance parallel programs to provide program visualization as well as data visualization. We plan to move our existing virtual reality software system, Flatland, to the new parallel machine to blend Flatland's multi-threading architecture with the parallel rendering capabilities of the new machine. In this new setting, we will experiment with applications where both the VR code and the application code are running on the same cluster, but on different sets of processor nodes. In addition, we will experiment with multiple virtual users within Flatland, again interacting with the application code. We expect that the programmer's level of comprehension will greatly increase when allowed to work in this new domain. The final products will be a deeper understanding of how to improve our understanding of complex information and systems, a working virtual laboratory for high performance program development and testing, and a better educational environment for our students.

Flatland, named in honor of Edwin Abbott's 1884 book by the same name, was written in the first half of 1999 to serve as a platform for our virtual reality research. It is currently installed at Los Alamos National Laboratory, Argonne National Laboratory, Sandia National Laboratories, The Phantom Works of The Boeing Company, and the Maui High Performance Computing Center. Flatland is a portable, cross platform Unix/Linux based multithreaded C/C++ based system that uses the graphics language OpenGL (or MESA) and associated libraries, including the GLUT library. A virtual environment (VE) is built from objects linked together in a world or scene graph, much like VRML or Open Inventor. Flatland has been designed to support a wide sensorium, including 3D graphics, 3D sound, 3D smell, simple haptics, and verbal conversations, both with artificial elements in the environment and other immersed workers. Each user operates from within their personal workspace represented as a surrounding dodecahedral vessel, which is flown through the VE and contains customizable consoles, screens, and controls, as well as their personal tool chest. The worker interacts with the vessel and environment through the use of custom hand held wands and the use of voice commands.

New programming models and new compiler technologies were required to easily and effectively program the MP-SMP machines, and at the same time, to produce efficient high performance programs. The University of New Mexico has successfully combined message passing with threads and compiler directive based systems to solve linear algebra problems. This work, which we call hybrid programming, is one of these new models. Little work has been done on the visualization of these combined programming systems, and no work has been done in 3D representations of these types of programming systems. These systems by their combined nature lend themselves to a multi-dimensional hierarchical visualization structure.
