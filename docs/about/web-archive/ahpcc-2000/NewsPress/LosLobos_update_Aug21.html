Status Update on the LosLobos Supercluster

The AHPCC is pleased to announce that the new 512 processor Linux Supercluster, LosLobos, has been installed and configured. The machine is running with 30 friendly users for initial operation. The National Computational Science Alliance begins allocating the machine on September 1st for NSF research. All of LosLobos' 256 nodes are running with the latest Myrinet drivers. These new drivers make use of the shared memory between processors within a node. In initial benchmarking, LosLobos have achieved latencies of less then 2 µ seconds measured within a node and less than 15 µ seconds between nodes. Also, two additional compilers, Absoft and NAG, have been added to the original configuration of GNU and PGI compilers.

LosLobos is also operating under Maui Scheduler, first developed by UNM's Maui High Performance Computing Center, which provides reservations and backfill features. This allows the machine to be used more efficiently. The official grand opening takes place on September 13, 2000 during the Linux Users Conference http://www.ahpcc.unm.edu/conf/.
