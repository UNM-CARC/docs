Linux Superclusters maximize capability while minimizing cost. The design combines commodity parts with a high bandwidth, low latency interconnect network to solve communication-intensive grand challenge problems.

Roadrunner provides production cycles for NSF funded scientific research as part of the Partnerships for Advanced Computational Infrastructure (PACI) Grid through the NCSA. Roadrunner also provides a development environment for advanced systems research in computer science and engineering.

Adding the Roadrunner Supercluster to the Grid ensures that scientists will have access to a testbed for computer scientists developing portable programming languages and to an environment to compare the performance of applicationsaccross different architectures. This includes both, traditional high performance computing applications and applications in the emerging national information infrastructure, including applications such as scalable web serving, interactive visualization/data exploration, information serving, and data mining.

Large allocations (>10,000 hrs) are granted to NSF scientists and researchers through the NCSA. Small allocations are granted by AHPCC. To apply for allocations you must meet certain eligibility requirements.

The Roadrunner Supercluster is a strategic collaboration with Intel Corp. and Alta Technologies
