Blackbear
 32   550 Pentium III 144 GB Dual SMP Myrinet Linux cluster
Blackbear is for general use as a development and production parallel machine. It is a high bandwidth, low latency interconnect machine. It is very good with jobs that require a lot of message passing between the processors. Blackbear can be used for classes. "Embarrassingly parallel" appelettes that do not require a HBLL interconnect should use Cochiti, or utilize the Condor Job Submission Capability to submit jobs on the Turing Cluster or RCDE boxes.
Turing Cluster
 24   600 Pentium III SMP Linux
The Turing Cluster is a group of 12 machines that serve dual purposes. The cluster acts as workstations for workshop attendees and also as a computation engine for naturally parallel jobs. These jobs are scheduled through Condor, which migrates the jobs to other machines when the cluster is used for a workshop.
Azul
 32   550 Pentium III 360 GB Quad SMP Gigabit Ethernet Linux cluster
Azul is the hardware side of a research project between AHPCC and IBM Research. A cluster of 32 processors (8 4-way NetFinity nodes) is joined together with a cluster of 32 processor Winterhawk machines with a Scalable Graphics Engine (SGE) to create a parallel computing, rendering and displaying environment. Access is allowed only to users who have been approved for the project. Please contact Dr. Bob Ballance for more information.
