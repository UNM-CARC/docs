    MASS
    AIX
    		This library can provide significantly faster transcendental functions with little impact on accuracy. To use the MASS library, link in the alternate mass library from the /usr/lib directory by adding the -lmass option to the compile/link line. Additional documentation is available at usr/lpp/mass/MASS.readme

    3.3 Parallel Software

    • Message Passing:

      Libraries
      Platforms
      Notes
      MPICH
      AIX, Linux, SGI
      		A public domain MPI from Argonne National Laboratory and Mississippi State University. The software can use the high speed switch. shared memory, or the ethernet.
      IBM-MPI
      SP/2
      		 
      PVM
      AIX, Linux, SGI
      		It runs either shared memory or IP over the ethernet. Examples are located in /usr/local/makefiles/pvm
      P4
      AIX, Linux, SGI
      		A public domain message passing library from Argonne. It runs on the high speed switch, shared memory, or over the ethernet. Examples are located in /usr/local/makefiles/p4


    • Data Parallel Compilers

      Libraries
      Platforms
      Notes
      IBM HPF
      AIX
      		The AHPCC is running a pre-lease copy and cannot run the general release due to hardware incompatibility. Additional documentation is available in /usr/lpp/xlhpf/postscript


    • Parallel Libraries:

      Libraries
      Platforms
      Notes
      PESSL
      AIX
      		PESSL stands for Parallel Engineering and Scientific Subroutine Library. It is an IBM product, available only for RS6000 and SP architectures.
    • PESSL Manual
    • Sample Makefile for C Programs
    • Sample Makefile for Fortran77 Programs
    • Sample Makefile for Fortran90 Programs
      • ScaLAPACK
      AIX, Linux
      		A public domain library from University of Tennessee which implements parallel versions of many of the linear algebra routines from LAPACK.
      PETSc
      AIX
      		A public domain library of parallel linear algebra routines from Argonne.
      NAG
      AIX
      		A proprietary library of parallel linear algebra routines from NAG. Early implementations ran on top of PVM, but current versions based on MPI are being installed at the AHPCC
      PIM
      AIX
      		A public domain library of parallel iterative methods
