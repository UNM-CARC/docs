Newsletter for March 2000

 

Hello everyone, it is that time again. We would like to update you on the
happenings of HPC systems group.

In this issue:
-512 processor
-Nambe Status
-SP2: No longer available
-Cochiti Status
-Help Desk Information: Saving Space

512 PROCESSOR:

The Alliance-UNM 512 processor (733 MHz) cluster with Myrinet will be
delivered by mid-April. IBM won the bid and we are looking forward to
installing the new supercluster. We will send out updates as this project
progresses.


NAMBE STATUS:

Nambe is now up and running as good as new. Along with a new power
supply, we have also upgraded to Irix .


SP2: No longer available

The SP-2 has left the building. Please use Blackbear.


COCHITI STATUS:

Cochiti is up and running with a new blower assembly, but its 9GB drive is
out of commission. It is mounting /usr/local off bonsai. We are
investigating the cost of a new 9GB drive and will keep you posted.


Help Desk Information: Saving Disk Space:

Disk space is limited in any computing environment. At the moment, AHPCC is
nearly at disk usage capacity. Much of our disk usage can be reduced if
we all take a few simple steps:

1. Compress large files. The unix utilities gzip and
compress are available on all systems.

2. Move files that you don't expect to access often to zip disks.
There are zip drives available on all rcde and turing boxes.

3. Use local scratch space (/usr/local/scratch) for temporary storage.
This includes sound and other entertainment files.


We will scan the system daily for core files, removing them as we find them.
If you have a file named core that you do not wish to have removed, please
rename it.

If you require a large amount of disk space (over 500M) for a specific project,
please submit a help request form and the systems group will see what can be
done.
