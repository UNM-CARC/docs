Hardware

***** NOTE *****

  • The HPCERC hardware configuration centers around several IBM Linux clusters. These systems are supported by a network of communications devices, a mass storage system, visualization hardware, file servers, PCs, Macintoshes and peripherals.



 
Machines-Systems

The complete list of systems including their compilers, schedulers, and user guides is located at http://www.hpc.unm.edu/docs/systems.html

 

Network Configuration

  • External Connectivity

    • T3 connection to the Abilene network and a T3 connection to the Internet backbone, with each connection offering transmission speeds of up to 45 megabits of data per second.

  • Internal Connectivity

    • Gigabit ethernet backbone & fast ethernet (100 Mbps)

    • The nodes in each SP system are internally connected within themselves by a high performance switch (40MB/sec).

    • SP external disk drives are connected to general purpose machines by SCSI (10MB/sec).


 
Other Machines

  • The HPCERC Visualization Lab includes a number of SGI machines (indigo, indy, onyx2) used primarily by onsite visitors/researchers or local users.

  • The HPCERC employs a number of other machines for various purposes:
    • File servers
    • Control workstations
    • Training / Workshop
    • DNS, NIS, Internal-only news server
    • WWW and anonymous FTP server
    • Mail servers
    • Testing
    • Guest machines
    • Staff machines
    • other special purposes

  • Most of these machines are inaccessible to users. Users should not attempt use any machine which is not approved for public use unless otherwise directed.

Software Documentation

  • Documentation for software installed on the general purpose systems can include any of the following:

    • Info pages
    • Man pages
    • Read me files
    • PostScript documents
    • On-line help (internal to the application)
    • HTML documents
    • InfoExplorer (IBM's on-line manuals)
    • Web links to Vendor materials

  • For documentation that is included with the package distribution, be sure to check its install directory. The HPC@UNM does not maintain a central repository of all software documentation.
  • Consult vendor WWW servers. Most software vendors have web pages which include product information and documentation.
 

IBM Software Documentation

WWW Resources

    The BEST place for documentation about IBM software products including the parallel environment, AIX operating system, hardware, technical reports and more, is located on IBM's various web pages. Some starting points:

    • SP Resources - probably the most complete source for SP information of all types

    • IBM Tech Resources - good place for technical reports and "internals" documentation.

    • IBM RS/6000 - covers the entire RS/6000 product line

    • IBM's homepage - if you can't find it anywhere else, this is the launching point.

Hardcopy

  • Ordering IBM Manuals: see the Services and Support section on IBM's home page

  • Many IBM Manuals are available free of charge by download from the various IBM web pages cited above.

Anonymous FTP is closed for security reasons. Please contact help@hpc.unm.edu for special requests.

Secure Access

  • HPC@UNM uses secure shell (ssh).
  • HPC@UNM supports the following ssh clients: 1) openssh for Unix, 2) putty for Windows
  • Other ssh clients may work. They are not supported by HPC@UNM. Your milage may vary.

Email
  • HPC@UNM currently supports PINE and Netscape email clients.
