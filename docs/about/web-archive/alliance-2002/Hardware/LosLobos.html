LosLobos is a research project with the Alliance. It provides a massively large linux cluster. The typical LosLobos user is 1) a member of the Alliance, 2) a HPC user, 3) Large-scale application.

  • Documentation- Users Guide
  • Compilers - GNU, PGI
  • MPICH
  • Numerical Libraries: BLAS, BLACS, ScaLAPACK, FFTw, PETSc
  • Scheduler - Maui
  • Applications: Cactus, MILC, GAMESS
