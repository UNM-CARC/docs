Access Grid Research at the AHPCC

What is the Access Grid?

The mission of the Access Grid is to provide a collaborative environment that complements the Alliance's Computational Grid, for remote visualization, application development, planning sessions, or other events or meetings. This the Access Grid can supplement more formal meetings between researchers with a high-bandwidth informal virtual meeting room.

Who created it?

The National Computational Science Alliance Access Grid (NCSA Access Grid) is an Internet-based conferencing system supporting real time, multi-point, group-to-group communication and collaboration. "Grid nodes," the access points, typically combine large-screen multimedia displays using conventional projectors with high-end audio support. Anode can be as small as an individual office, or as large as an auditorium. The Access Grid substrate is the Internet, using IP multicast and middleware to feed the nodes.

What types of collaborations are possible on the Access Grid?

Access Grid users can share presentations, visualization environments, browsers, whiteboards and graphics tablets, and even remote sensors and devices. Early research indicates that the Access Grid provides a space in which participants can freely and informally interact.

How is it used for research?
As nodes come on-line, the Access Grid provides a research platform for developing distributed data and visualization conduits and for studying distributed, creative collaboration. The Access Grid assists its own development by providing the means for collaboration among Alliance Grid system researchers.

Who is the AHPCC's contact for the Access Grid?

John Greenfield can help you schedule a time to use the Access Grid.

How can I jump on the Access Grid?
Organizations must either build a "node" or find a local access point.

There are several steps to building a node:
1. Download Audio Algorithm
2. Download Video Algorithm
3. Get at least a T1 for bandwidth- call local telephone company.
4. Set up the equipment according to this configuration
5. Have a microphone, camera, computer, video card, audio card, T1.
