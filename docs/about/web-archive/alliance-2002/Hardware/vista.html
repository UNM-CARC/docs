The Vista machine is the Main hardware component of the second phase of the Vista Azul Project. The first phase of the project involved the set up of the Azul machine. Now both will be networked together in this joint IBM and UNM project that is interested in hybrid interoperability.

Currently Vista is being set up and then will need time for programming so that it is able to interface with Azul. For more information visit the Vista Azul Project page.

Vista is for restricted use
