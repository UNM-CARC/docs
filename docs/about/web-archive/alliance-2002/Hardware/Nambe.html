Nambe is primarily used in visualization research and shared memory parellel computation. WARNING: Computations should be completed in non-working hours (5 pm - 8 am Mountain Time) because its primary use is as a visualization machine. It is located in the AHPCC's visualization lab. It has a CD drive & sound. It can run stereo 3D visualization. Typical users of Nambe are often 1) researchers in visualization, 2) OpenGL developers, 3) parallel computation users.

Please refrain from using Nambe for anything other than production jobs. We have noticed that there are several users that have been using Nambe for netscape and such. This machine is not for that purpose.

  • Documentation- IRIX.pdf
  • Compilers: C++, C, f77, f90
  • MPI version is for IRIX and MPICH
