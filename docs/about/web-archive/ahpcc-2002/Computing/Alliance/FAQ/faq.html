MPI Programs

  1. How do I compile my MPI program on your machines?
    • There are several guides for compiling MPI code on our various platforms: Linux cluster. Typically, you can use the MPI compile scripts (mpif77 and mpicc on the Alta and Linux clusters and mpxlf anf mpcc on the SP2).

LosLobos

Roadrunner

1. How come the compiler is not able to find the mpif90 programs?

You need to specify an mpihome in your .cshrc. See the following webpages for more information: http://www.ahpcc.unm.edu/Computing/AHPCC/Documentation/User_Guides/compile.html
