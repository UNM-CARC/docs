Truchas is a 12-node Linux cluster that was purchased and built in collaboration with the UNM Center for Particle Physics. It is used for general purpose serial computing, for AHPCC Workshops, and for high-throughput particle physics simulations run under the Condor software system. http://www.ahpcc.unm.edu/Condor/index.html
