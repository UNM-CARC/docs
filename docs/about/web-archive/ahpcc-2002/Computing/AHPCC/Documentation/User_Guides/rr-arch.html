Roadrunner Architecture and System Configuration

Roadrunner is a cluster of 64 individual computing nodes, each with 2 CPUs per node, for a total of 128 processors. A high-speed, low latency Myrinet network interconnects the 64 nodes, and a Fast Ethernet network connects the cluster to file servers and the Internet. Login access is provided via an additional four nodes.
