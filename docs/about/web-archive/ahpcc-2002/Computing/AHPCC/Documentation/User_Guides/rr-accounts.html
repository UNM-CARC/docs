1.0 Managing your account

1.1 Changing your password

A default password is sent to you as part of the new user packet you receive via postal mail after your account is created. You should change your password the first time you login to the cluster and periodically thereafter.

NOTE: If you are using an Alliance digital certificate to access your Roadrunner account you will not receive a default password through the mail. The private key that is part of your certificate provides the security you need.

You use the yppasswd command to change your password:

$ yppasswd
Changing NIS account information for janeuser on agave.alliance.unm.edu.
Please enter old password:
Changing NIS password for janeuser on agave.alliance.unm.edu.
Please enter new password:
Please retype new password:

The NIS password has been changed on agave.alliance.unm.edu.

Enter your old or current password when prompted, and then enter your new or desired password when prompted. You will be asked to enter your new password again for verification.

NCSA offers a webpage with tips on selecting good passwords that you should consider when you change your password.

1.2 What if I have forgotten my password?

You may contact the Alliance Consulting Office and request that your password be reset to the default. The consulting staff will not disclose your default password so you must retain the original copy sent to you as part of the new user packet. It is important that you keep the new user packet information that contains your default password in a secure place for your reference. If you do not have this form available when you need it, you will forced to wait until a duplicate can be mailed to you using postal mail.

1.3 Changing your default shell

When your account is first activated your default shell is set to tcsh, an advanced version of the Berkeley UNIX C shell (csh). The tcsh shell is completely compatible with the standard csh, and all csh commands and scripts work unedited with tcsh. Enter "man tcsh" at a Roadrunner prompt for details about tcsh.

Other shells available on the cluster include the GNU Bourne-Again SHell (bash), which is completely compatible with the Bourne shell (sh), and a public domain version of the Korn shell (ksh). Neither csh nor sh are available, though for compatibility reasons /bin/sh and /bin/csh exist on the cluster as links to the compatible shells bash and tcsh.

To change your default shell use the ypchsh command:

$ ypchsh
Changing NIS account information for janeuser on agave.alliance.unm.edu.
Please enter password:

Changing login shell for janeuser on agave.alliance.unm.edu.
To accept the default, simply press return. To use the
system's default shell, type the word "none".
Login shell [/bin/tcsh]: /bin/bash

The login shell has been changed on agave.alliance.unm.edu.
