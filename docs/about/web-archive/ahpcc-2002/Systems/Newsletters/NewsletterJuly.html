LosLobos Update

We are pleased to announce that LosLobos, AHPCC’s newest supercluster
(512 processors with Myrinet) is installed. Already the Maui Scheduler
and the Linux Resource Manager are configured on LosLobos. We will be
posting more updates when LosLobos is ready for users.

Linux Supercluster Users Conference

September 11-15, 2000, the AHPCC will be hosting the Fall Linux
Supercluster Users Conference. Sponsored by IBM and UNM, the conference
will feature keynote speaker Jon *Maddog* Hall, Executive Director of
Linux International, and author of Linux for Dummies. Other keynote
speakers will be Dave Turek, Vice President, Deep computing, Web
servers, IBM, and Frank Glifeather, Executive Director, HPCERC, UNM.
The conference will also mark the Grand Opening for the LosLobos
Supercluster

August Alliance Chautauqua Conference

Alliance Chautauquas are road shows hosted by the National
Computational Science Alliance. Chautauqua showcases the power of
computational grids to link people and technologies in ways that change
how we communicate, conduct research, and do business.
The Chautauqua took place place Aug. 1-3 at the University of Kansas
in Lawrence. General information is available at:
http://alliance.ncsa.uiuc.edu/chautauqua/.
Those interested in the Kansas Chautauqua can register at:
http://www.kuce.org/app/chautauqua/.

Truchas – New Turing Cluster

Truchas, the new turing cluster located in the Workshop will run on
Linux. The computers have arrived and have been set up. ‘Windows’ will
be available on these machines through VMWare.

Vista Azul Moving to Phase II

AHPCC's collaboration with IBM through the Vista Azul projects has been
a success. Phase I of the project involved setting up a Linux cluster
on 8 (4-way Netfinity 5500 nodes with 550 MHz Xeon). With the success of
that task, Vista Azul is ready for Phase II. In Phase II, Vista Azul
will have new SP technology and SGE (Scalable Graphics Engines).

New Web Page

Our web page has a new look and format. This is an on-going project.
The Systems Group will be updating on-line documentation and adapting
the web page to make it a more effective tool that will reflect new
systems and growth at AHPCC. Upcoming will be new and improved User
Support, including an updated on-line Help Desk and a New User Guide, a
printable on-line manual for new users.
