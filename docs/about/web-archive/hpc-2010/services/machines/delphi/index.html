Delphi

by Jared Galbraith — last modified 2006-08-28 01:55 AM

IBM X-342 8 node cluster with 2TB FC storage.

The delphi system is a 4 dual CPU cluster of IBM X-342 Netfinity servers connected to a FAStT500 fiber channel storage subsystem with 2TB of raw storage.  It's raison d'etre is to host an Oracle Real Application Cluster (ORAC) data warehouse of genomic/bioinformatic data.
