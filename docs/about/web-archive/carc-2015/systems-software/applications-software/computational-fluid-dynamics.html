Computational Fluid Dynamics & Multiphysics

CARC supports open source and licensed computational fluid dynamics and multiphysics (CFD&M) software on its supercomputers and cluster machines. The capabilities of the codes include analysis of laminar and turbulent flows, aerodynamic analysis, heat transfer in fluids and solid media, calculation of full body loads, dynamic vibration, multibody systems, optimization, and uncertainty quantification.  

Open source software on CARC machines is available for use without a paid license. Proprietary software requires a valid license which must be provided by the user. For assistance in utilizing an exsiting license on CARC machines, please contact help@carc.unm.edu. CARC also can host license servers upon request. For for installation of software not on the lists below please see here. 

Custom-designed workshops for specific codes or workflows can be designed in collaboration with CARC Applications Scientists and Systems staff. For inquiries, please contact director@carc.unm.edu. 

Code/Software Suite License Type Installed Versions Machines Description Links
OpenFOAM Open Source 3.0+, 2.3.0 (Ulam only) Ulam, pequena, nano (!), Metropolis, Xena Open-source CFD software with an extensive range of solvers, preprocessing and post processing utilities. Official website; Documentation; Wiki; Forums
Star-CCM+ Proprietary 7.0.6, 8.06, 9.04, 10.04 Ulam, pequena, Metropolis, nano CFD software for solving problems involving flow (of fluids or solids), heat transfer and stress. Official website; Documentation
ABAQUS Proprietary 6.14 Ulam FEA suite that allows computation of full body loads, dynamic vibration, multibody systems, impact/crash, nonlinear static, thermal coupling, and acoustic-structural coupling Official website; Documentation
COMSOL Multiphysics Proprietary 5.1, 4.2a Ulam General-purpose software platform, based on advanced numerical methods, for modeling and simulating physics-based problems. Simulation Tool for electrical, mechanical, fluid flow, and chemical applications Official website; Documentation (*); Quickbyte

(*) : Additional COMSOL documentation is included with installation package. 

(!) : OpenFOAM installation is limited to solvers only on this machine. Pre and post processing must be performed on other CARC machines or your local desktop.

In addition to CFD&M software, CARC machines are equipped with powerful analysis tools for optimization, sensitivity analysis and uncertainty quantification.

Code/Software Suite Licenses Installed Versions Machines Description Links
Dakota Open Source 6.4, 6.2 6.4: Ulam, Xena, Metropolis; 6.2: Ulam, nano Toolkit with a variety of iterative systems analysis methods, including optimization, uncertainty quantification, nonlinear least squares methods, and sensitivity/variance analysis. Official website; Documentation

To request additional software installation please email help@carc.unm.edu
