# Tutorials

Domain-science QuickBytes: complete worked examples from genomics to materials science.

* [Variant calling with GATK](gatk.md) - A genomics variant-calling workflow using GATK best practices on CARC systems.
* [Metabarcoding analysis](metabarcoding.md) - Process environmental DNA metabarcoding data on CARC clusters.
* [RAD-seq analysis with Stacks](stacks.md) - Analyze restriction-site associated DNA sequencing (RAD-seq) data with Stacks.
* [Genome assembly evaluation with QUAST and BUSCO](genome-evaluation.md) - Evaluate genome assembly quality and completeness with QUAST and BUSCO.
* [Coalescent simulation with msprime](msprime.md) - Simulate genealogical histories and genome sequences with msprime.
* [Demographic inference with PSMC](psmc.md) - Infer population size history from diploid genomes using PSMC.
* [Bayesian phylogenetics with BEAST](beast.md) - Run BEAST Bayesian evolutionary analyses on CARC clusters.
* [SimCov epidemiological simulation](simcov.md) - Run the SimCov agent-based model of SARS-CoV-2 infection dynamics in lung tissue.
* [VASP materials simulation](vasp.md) - Set up and run VASP density-functional-theory calculations on CARC clusters.
* [ORCA quantum chemistry](orca.md) - Run ORCA quantum chemistry calculations in parallel on CARC clusters.
* [Parallel CASA for radio astronomy](mpi-casa.md) - Run mpiCASA for parallel radio astronomy imaging on CARC clusters.
